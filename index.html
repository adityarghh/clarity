Recommended source
DDInter 2.0 / third-party harmonized JSON

The compatible knowledge base links drug names and identifiers to interaction severity and mechanism descriptions. It is a third-party compilation derived from DDInter 2.0, not an official DDInter export.

Open JSON download page ↗ Official DDInter downloads ↗

The full JSON is large (about 35 MB). On GitHub, use the download/raw option and then select the saved file above.

ⓘ
Coverage and license. DDInter is an academic database, not a regulator-approved clinical decision system. The source data is licensed for non-commercial use with attribution. Review the source repository's license, attribution and healthcare disclaimer before using or redistributing it.
What changes after import?
01 / Lookup
Match drug names

Generic names and known aliases in the imported file are normalized for pair matching.

02 / Evidence
Show recorded severity

Severity and mechanism are shown only when present in the source record; missing fields remain unknown.

03 / Gaps
No false reassurance

A pair absent from the loaded dataset is reported as a coverage gap, not as safe or interaction-free.
